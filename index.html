ModGuard

As of October 2026, ModGuard has run more than 50,000 scans and flagged about 3,000 files.

Minecraft mods are just Java archives, and some of them ship token stealers and remote access trojans. ModGuard looks inside the file before it ever runs. I add detections based on what users send in. It's at modguardprotection.com.
